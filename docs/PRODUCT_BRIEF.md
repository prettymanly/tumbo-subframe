# 🎯 Tümbo - Product Brief

## Project Overview
**We are building:** A public-facing class directory for children's activities that feels polished, loads fast, and is ready to integrate AI-powered recommendations in later phases.

**Target audience:** Parents seeking children's classes and activities, with a focus on Singapore market initially.

**Primary benefits:** 
- Fast, searchable directory of quality children's classes
- SEO presence for organic discovery
- Foundation for future AI-powered personalization
- Data-ready backend for automated content ingestion

**Key features:**
1. **Public Class Directory** - Grid/list views, search, filters (location, age, subject, price)
2. **Class Detail Pages** - Rich information, schedules, provider details, CTAs
3. **Provider Profiles** - Verified listings with class offerings
4. **Basic CMS** - Supabase-powered data management
5. **Scraping-Ready Backend** - Automated data ingestion pipeline

**High-level tech:** Next.js 15 + React 19, Tailwind CSS, Supabase (PostgreSQL + Auth + Storage), Node.js scraping scripts, OpenAI GPT-4 (Phase 2)

## Development Phases
- **Weeks 1-3:** Frontend + DB setup, deploy to Vercel
- **Weeks 4-5:** Scraping integration, automated data pipeline
- **Weeks 6-8:** Polish, testing, user feedback

## Success Metrics
- Landing → first class view: < 20 seconds
- 100+ quality class listings in database
- 10+ organic leads to providers within 1 month
